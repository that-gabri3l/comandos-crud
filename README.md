# Atividade para pratica de comandos CRUD no SQL

Neste repositorio ha exemplos de utilização de comandos **CRUD**:

-CREATE -> comando INSERT (inserir/cadastrar)
- READ -> comando SELECT (selecionar/consultar/obter/ler)
- UPDADTE -> comando UPDADTE (atualizar/editar/modificar)
- DELETE -> comando DELETE (deletar/excluir/remover)
